# iOS 26 风格模拟通话记录 V6

## V6 仅增加两项功能

1. 输入 `15069488015,8842` 后，列表和完整通话详情显示 `15069488015,8842`，并支持原样保留分隔符 `,` / `;` 及以零开头的 4 位转机码。编辑、复制、分享、备份、导入也保留。
2. 批量生成时支持勾选「随机分配通话时间」，设置开始/结束的日期时间，单条记录随机分配到该范围内。选择「呼出」自动开启；你也能关闭随机开关，沿用旧的时间生成方式。

## 无自己的服务器：免费 GitHub Pages

1. 注册/登录 github.com，新建名为 `liquid-calls` 的 Public 仓库。
2. 将本压缩包的 `index.html`、`manifest.webmanifest`、`service-worker.js`、`icons/` 目录上传到仓库**根目录**（不要把 ZIP 本身作为网站上传）。
3. 打开仓库 Settings > Pages；Source 选 Deploy from a branch；Branch 选 main，文件夹选 /(root)；保存。
4. 在 Safari 打开 `https://<GitHub用户名>.github.io/liquid-calls/`；分享 > 添加到主屏幕 > 开启「作为 Web App 打开」> 添加。
5. 之后点桌面「最近通话」图标即可进入近似独立 App 窗口，无 Safari 工具栏。**手机系统状态栏仍由 iOS 管理，普通 HTML 不可真正强制全屏。**

不要把真实手机号列表/JSON 数据提交到公开仓库。这个程序只把自己输入的记录保存在打开它的浏览器本地（localStorage）；安装后为另一独立 Web App 存储环境时，之前的 Safari 数据不一定自动同步，请通过 JSON 备份/导入迁移。

## 其他

纯静态，无后端。首次需要通过 HTTPS 成功打开并安装/缓存，之后在支持的环境中可离线访问。只是模拟界面，不会修改手机真实通话记录。
